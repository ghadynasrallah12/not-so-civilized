# not-so-civilized

Client portfolio website project.

## Local development

```bash
npm run dev
```

Then open `http://127.0.0.1:4173`.

## Deploy to Vercel

1. Create a new project in Vercel.
2. Set the root directory to `not-so-civilized` (if your repository contains multiple projects).
3. Keep default build settings for a static site.
4. Deploy.
